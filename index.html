HELP & POLICY

이용 안내

실제 운영 기능과 샘플 범위, 커뮤니티 이용 원칙을 안내합니다.

빌드는 어떻게 적립하고 사용하나요?

Google 로그인 후 일반 글이나 댓글을 등록하면 각각 1빌드가 적립됩니다. 삭제하면 그 1빌드도 취소됩니다. 쇼츠 영상은 저장 성공 시 5빌드를 사용하며 쇼츠 게시판 등록에는 추가 적립이나 차감이 없습니다.

샘플 데이터란 무엇인가요?

화면 구성과 이동을 확인하기 위한 가상의 작업·결과·파일입니다. 모든 항목에 샘플 표시가 붙으며 실제 데이터가 아닙니다.

실제 파일이 전송되나요?

회의록 화면의 TXT·MD·SRT·VTT 파일은 브라우저에서 글자만 읽어 AI 서버로 전달합니다. 쇼츠는 MoneyPrinterTurbo(MPT)가 만든 MP4 또는 브라우저가 만든 WebM을 인증된 저장소에 보관하며, 사용자가 게시 버튼을 누르기 전에는 공개되지 않습니다.

API 키는 어디에 저장되나요?

사용자 브라우저에는 저장하지 않습니다. Jeremy 관리자 계정이 입력한 키만 서버에서 암호화해 보관하며, 저장 후 화면에 다시 표시하지 않습니다.

게시판 로그인과 개인정보는 어떻게 처리하나요?

Builders Lounge에서는 Google 로그인 계정 이름으로 글과 댓글을 작성합니다. 로그인 토큰은 현재 탭의 메모리에만 유지합니다. 공개 글에는 일반 텍스트만 허용하므로 개인정보·비밀값·내부 경로를 작성하지 마세요.

부적절한 글이나 운영 문제는 어디에 알리나요?

하단 문의하기 또는 hello@ai-hub-os.com으로 글 주소와 사유를 보내 주세요. 운영자는 Report Hub와 공유된 관리자 기능으로 필요한 조치를 확인합니다.

뉴스레터·영상·프롬프트 출처는 어디인가요?

Vault 후보를 공개 가능한 내용으로 다시 작성하고 원문 링크를 붙입니다. 외부 뉴스레터·영상·기사 전문을 복사하지 않으며, 원본 프로젝트와 YouTube는 사용자가 직접 열 때만 불러옵니다.

게임과 영상이 보이지 않으면 어떻게 하나요?

브라우저가 iframe을 차단할 수 있습니다. 각 카드의 새 탭 링크로 원본을 열어 주세요. 자동 재생은 하지 않고 선택한 콘텐츠 하나만 표시합니다.

메뉴와 보기 설정을 초기화하려면?

설정에서 보기 밀도와 샘플 표시를 바꿀 수 있습니다. 브라우저 저장값을 지우면 기본값(여유 있게·샘플 표시)으로 돌아갑니다.
