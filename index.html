HELP & POLICY

이용 안내

실제 운영 기능과 샘플 범위, 커뮤니티 이용 원칙을 안내합니다.

빌드는 어떻게 적립하고 사용하나요?

Google 로그인 후 일반 글이나 댓글을 등록하면 각각 1빌드가 적립됩니다. 삭제하면 그 1빌드도 취소됩니다. 쇼츠 영상은 저장 성공 시 관리자 설정 비용을 사용하며 쇼츠 게시판 등록에는 추가 적립이나 차감이 없습니다.

샘플 데이터란 무엇인가요?

화면 구성과 이동을 확인하기 위한 가상의 작업·결과·파일입니다. 모든 항목에 샘플 표시가 붙으며 실제 데이터가 아닙니다.

실제 파일이 전송되나요?

쇼츠는 MoneyPrinterTurbo(MPT)가 만든 MP4 또는 브라우저가 만든 WebM을 인증된 저장소에 보관하며, 사용자가 게시 버튼을 누르기 전에는 공개되지 않습니다.

API 키는 어디에 저장되나요?

사용자 브라우저에는 저장하지 않습니다. Jeremy 관리자 계정이 입력한 키만 서버에서 암호화해 보관하며, 저장 후 화면에 다시 표시하지 않습니다.

게시판 로그인과 개인정보는 어떻게 처리하나요?

Builders Lounge에서는 Google 로그인 계정 이름으로 글과 댓글을 작성합니다. 로그인 토큰은 현재 탭의 메모리에만 유지합니다. 자세한 수집 항목과 삭제 요청 방법은 개인정보 처리 안내에서 확인할 수 있습니다.

부적절한 글이나 운영 문제는 어디에 알리나요?

글과 댓글의 신고 링크를 누르면 항목 번호와 주소가 포함된 운영 메일을 보낼 수 있습니다. 직접 문의할 때는 hello@ai-hub-os.com으로 글 주소와 사유를 보내 주세요.

뉴스레터·영상·프롬프트 출처는 어디인가요?

Vault 후보를 공개 가능한 내용으로 다시 작성하고 원문 링크를 붙입니다. 외부 뉴스레터·영상·기사 전문을 복사하지 않으며, 원본 프로젝트와 YouTube는 사용자가 직접 열 때만 불러옵니다.

게임과 영상이 보이지 않으면 어떻게 하나요?

브라우저가 iframe을 차단할 수 있습니다. 각 카드의 새 탭 링크로 원본을 열어 주세요. 자동 재생은 하지 않고 선택한 콘텐츠 하나만 표시합니다.

메뉴와 보기 설정을 초기화하려면?

설정에서 보기 밀도와 샘플 표시를 바꿀 수 있습니다. 브라우저 저장값을 지우면 기본값(여유 있게·샘플 표시)으로 돌아갑니다.

사람과 결과물을 존중합니다

Builders Lounge는 AI를 만들고 배우는 사람이 경험을 공유하는 커뮤니티입니다. 의견이 달라도 사람을 공격하지 않고, 공개 권한이 있는 내용만 올립니다.

게시할 수 없는 내용

  • 불법 행위, 사기, 피싱 또는 위험한 행동을 돕는 내용
  • 특정인을 모욕하거나 위협하고 차별과 혐오를 조장하는 내용
  • 타인의 개인정보, 비밀번호, API 키, 내부 경로와 비공개 자료
  • 반복 광고, 도배, 악성 링크와 서비스 운영을 방해하는 내용
  • 저작권, 상표권, 초상권 등 타인의 권리를 침해하는 자료
  • 설명 없이 실제 사람으로 오인하게 만드는 조작 이미지와 영상

신고와 운영 조치

각 글과 댓글의 신고 링크에서 항목 번호, 주소, 신고 사유를 운영 메일로 보낼 수 있습니다. 운영자는 내용을 확인한 뒤 게시물이나 댓글을 삭제하거나 계정을 제한할 수 있습니다. 조치에 이견이 있으면 같은 메일로 재검토를 요청할 수 있습니다.

빠른 신고

신고 대상 주소와 이유를 함께 보내 주세요. 긴급한 범죄나 신체 위협은 서비스 메일보다 관계 기관에 먼저 연락해 주세요.

Google 계정으로 로그인하면 Builders Lounge 계정이 생성됩니다. 사용자는 본인 계정을 사용하고, 계정으로 이루어진 활동과 공개 게시물에 책임을 집니다. 서비스 운영을 방해하거나 다른 사람의 권리를 침해하면 게시물 삭제 또는 계정 이용 제한이 이루어질 수 있습니다.

게시물과 AI 결과물

사용자가 작성한 게시물의 권리는 사용자에게 있습니다. 사용자는 서비스가 게시물을 화면에 표시하고 운영하는 데 필요한 범위의 이용을 허락합니다. AI 결과물은 오류나 권리 문제가 있을 수 있으므로 공개·배포 전 사용자가 사실과 권리를 확인해야 합니다.

빌드 포인트

빌드는 사이트 안에서 AI 도구 사용량을 표시하는 운영 포인트이며 현금이나 전자금융 수단이 아닙니다. 글과 댓글 삭제, 작업 실패, 관리자 조정에 따라 잔액이 달라질 수 있습니다. 유료 판매를 시작하기 전에는 별도 가격과 환불 기준을 먼저 안내합니다.

서비스 변경과 책임 범위

외부 AI 제공자, 저장소, 로그인 서비스의 장애나 정책 변경으로 일부 기능이 일시 중단될 수 있습니다. 중요한 결과물은 사용자가 별도로 보관해 주세요. 운영정책이나 약관이 바뀌면 시행일과 변경 내용을 이 화면에 알립니다.
