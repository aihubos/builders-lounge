# Builders Lounge

AI Builders Lab의 도구·콘텐츠·커뮤니티를 한곳에서 탐색하는 공식 Builders Lounge 허브입니다. Report Hub 상단 메뉴와 Builders Lab의 네이비·블루 톤을 유지하면서, 국내 커뮤니티 포털의 빠른 탐색 구조와 토스·원티드 계열의 명확한 행동 흐름을 결합했습니다.

## 공개 주소

- Builders Lounge: https://aihubos.github.io/builders-lounge/

현재 버전은 커뮤니티와 AI 제작 기능을 한 계정으로 연결합니다. 브랜드 헤더, 통합 검색, 데스크톱 탐색, 모바일 하단 메뉴, 프롬프트 검색·복사, 뉴스레터 읽기, 영상·게임 선택 실행, 이미지 게시판 확대, 통합 게시판, 작업 상태 필터, 결과 미리보기, 보기 설정과 방문 집계가 동작합니다. `웹툰 제작기`와 `세계명화 프롬프트`는 해당 메뉴에 들어왔을 때만 화면 안에 불러오며 새 탭 열기도 제공합니다.

Google 로그인 후 자유게시판에 새 글을 등록하면 1빌드가 적립됩니다. AI 쇼츠 스튜디오는 사이트 Google 로그인 후에만 제작할 수 있고, 제작 진행률을 표시하며 AI가 만든 장면·화면·내레이션·자막을 사용자가 고친 뒤 최종 영상을 만듭니다. 영상 저장 비용은 관리자 설정을 화면에 그대로 표시하며, 실패·취소·30분 만료 시 예약을 해제합니다. 쇼츠를 게시판에 등록해도 추가 적립이나 차감은 없습니다. 다른 AI 제작 기능에도 관리자 설정 비용이 사용됩니다. 작업·결과물·파일은 계속 샘플로 구분합니다.

## 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 확인과 빌드

```bash
npm run check
npm run build
npm run test
```

빌드 결과는 루트 `index.html`, `styles.css`, `assets/`, `lounge/` 지원 파일, `robots.txt`, `sitemap.xml`, `.nojekyll`만 공개 경로에 포함합니다. sitemap에는 Builders Lounge 루트 주소만 등록합니다.

## 작업공간 범위

현재 화면에서 홈, 통합 검색, 쇼츠 제작안, 웹툰 제작기·세계명화 프롬프트, 프롬프트 모음, `AI 빌더스 랩 뉴스레터`, 영상 모음, 이미지 게시판, 게임방, Report Hub 통합 자유게시판, 빌드 내역, 관리자 설정, 작업·결과물·파일, 설정·도움말을 확인할 수 있습니다. 공개 콘텐츠는 정적 데이터와 연결된 게시판 응답으로 구성하며 개인 경로·비공개 문서를 복사하지 않습니다. 샘플 데이터 숨기기는 작업·결과물·파일에만 적용되고, 커뮤니티와 빌드 원장은 유지됩니다.

관리자 화면에서는 도구별 공급자·주소·모델·키·시스템 지시문·빌드 가격·활성 여부, 멤버 빌드와 관리자 권한을 관리합니다. 관리자 화면은 관리자 계정으로 로그인한 뒤에만 처음 진입할 때 불러옵니다.

## 저장소 운영

`styles.css`와 `assets/`는 정적 배포 호환을 위해 유지합니다. Lounge 화면의 스타일과 동작은 `lounge/` 아래 파일에서 관리합니다.

인증과 도구 요청은 연결된 서비스 계약을 따릅니다. AI API 키, 로그인 토큰, 비밀번호와 결제정보는 저장소나 공개 문서에 넣지 않습니다.
