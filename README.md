# Builders Lounge

AI Builders Lab의 도구·콘텐츠·커뮤니티를 한곳에서 탐색하는 정적 Builders Lounge입니다. Report Hub 상단 메뉴와 Builders Lab의 네이비·블루 톤을 유지하면서, 토스처럼 명확한 행동 흐름과 원티드처럼 콘텐츠를 발견하는 카드 구조를 결합했습니다.

## 공개 주소

- Builders Lounge: https://aihubos.github.io/builders-lounge/

이번 버전은 커뮤니티 MVP이며 실제 AI 처리 기능은 포함하지 않습니다. 메뉴 이동, 프롬프트 검색·복사, 뉴스레터 읽기, 영상·게임 선택 실행, 짤방 확대, 통합 게시판 CRUD, 작업 상태 필터, 결과 미리보기, 보기 설정, 샘플 표시 설정과 방문 집계가 동작합니다. `웹툰 제작기`, `세계명화 프롬프트`, `토큰 비용 계산기`는 왼쪽 메뉴를 누르면 원본 공개 앱을 오른쪽 본문에 표시하며 새 탭 열기도 제공합니다.

## 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 확인과 빌드

```bash
npm run check
npm run build
npm run test
```

빌드 결과는 루트 `index.html`, `styles.css`, `assets/`, `lounge/` 지원 파일, `robots.txt`, `sitemap.xml`, `.nojekyll`만 공개 경로에 포함합니다. sitemap에는 Builders Lounge 루트 주소만 등록합니다.

## 작업공간 범위

현재 화면에서 홈, 웹툰 제작기·세계명화 프롬프트·토큰 비용 계산기 원본 앱, 프롬프트 모음, `AI 빌더스 랩 뉴스레터`, 영상 모음, 짤방, 게임방, Report Hub 통합 자유게시판, 작업·결과물·파일, 사용량, 멤버십, 설정·도움말을 확인할 수 있습니다. Vault 콘텐츠는 공개용으로 다시 작성한 정적 데이터만 포함하며 개인 경로·비공개 문서·API 키를 복사하지 않습니다. 샘플 데이터 숨기기는 작업·결과물·파일·사용량에만 적용되고, 커뮤니티 콘텐츠는 유지됩니다.

정확한 연결 주소와 권한이 승인되기 전까지 `AI 회의록`과 `AI 쇼츠 스튜디오`는 연결 예정 상태로 유지합니다. 외부 통신은 방문 집계, 통합 게시판 API, 사용자가 선택한 원본 앱·YouTube·게임 iframe만 허용합니다.

## 저장소 운영

`styles.css`와 `assets/`는 정적 배포 호환을 위해 유지합니다. Lounge 화면의 스타일과 동작은 `lounge/` 아래 파일에서 관리합니다.

비밀키, 토큰, 비밀번호, 결제정보를 저장소나 공개 문서에 넣지 않습니다.
